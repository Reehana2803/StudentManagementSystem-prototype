1. Login Screen

LoginPrototype.java

Provides user authentication with default administrative credentials. Supports pressing Enter key from fields and displays interactive error/success dialogs.

Default Login: admin / admin (or 1234)

2. Dashboard Hub

DashboardPrototype.java

Central navigation hub. Displays the dynamic count of registered students and connects to Add, View, Update, Delete, Search, and Logout actions.

3. Add & Update Student

AddStudentPrototype.java

Robust form handling with full client-side validation: positive integer ID check, duplicate detection, age range (5-120), phone regex, and email validation.

4. Student Records Table

StudentListPrototype.java

Interactive JTable loaded directly from CSV storage. Features real-time as-you-type search filtering, row selection for updates and deletions, and refresh.
